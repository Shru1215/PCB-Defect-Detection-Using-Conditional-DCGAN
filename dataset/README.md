# Dataset

This project uses the DeepPCB dataset for training and evaluation.

## Dataset Information

- **Dataset Name:** DeepPCB
- **Number of Defect Classes:** 6
  - Open
  - Short
  - Mousebite
  - Spur
  - Copper
  - Pin-hole

## Dataset Split

- Training Images: 1200
- Validation Images: 300

## Note

The complete dataset is not included in this repository because of its large size.

You can download the dataset from the official DeepPCB source.
