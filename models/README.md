# Models

This folder contains the trained deep learning models used in this project.

## Models Used

- Conditional DCGAN – Used to generate synthetic PCB defect images.
- YOLOv12-S – Used to detect PCB defects from PCB images.

## Note

The trained model weights (`.pt` files) are not included in this repository because they are too large for GitHub.

You can train the models using the notebook provided in the `notebooks` folder.
